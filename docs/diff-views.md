# 差异视图（每种格式怎么呈现）

四种视图对齐同一条产品规则：**左边是文件本身，右边是变更清单，点一条就跳到真实位置并高亮**。

| 格式 | 视图 | 引擎 | 关键点 |
|---|---|---|---|
| Excel | 格级网格 + 变更清单 | `rules-core.wasm`（`sheet_diff`） | 只画有差异的行/列并带一行上下文；绿=新增、红=删除、黄=改动、蓝=公式、紫=样式；清单按「先行后列」排序，`j/k` 或上/下一项逐个跳，点行会把格子滚到视野并闪烁 |
| Word | 段落按序对齐 + 改动字标记 + 移动标注 | rules-core 内核直接读 OOXML | 清单由内核的段落修订生成：连续增/删合并为一条「改」，文字相同的 move-from/to 判为「移」 |
| PDF | 页面渲染 + 字符级高亮框 + 变更清单 | pdf.js + `@diffs/core-pdf` | 读文本层与每个字符项的坐标，按行对齐后把改动行的矩形画在页面上；没有文本层的扫描页明确报「无文本层」，不假装比对 |
| 代码 | 行级 diff + 符号图 | `rules-core.wasm`（`ls_diff` / `ls_graph`） | 区分注释/字符串/数字；符号表带定义行、体范围、引用行；右侧符号图给出跨文件引用数与 import 边 |

## 状态隔离（曾经的 bug）

切换样例时旧结果会残留、徽章会串。现在每次 `run()`：

1. 先把**所有**结果槽清空（xlsx / docx / pdf / 富文本 / 纯文本）；
2. 带一个**代次号** `gen`，异步引擎（Rust 内核 / pdf.js）回来时代次不符就丢弃结果。

回归测试：`pnpm test:ui`（真浏览器，跑一遍「每个 tab 点两次 + 样例乱序切换 + 四种视图断言」）。

## 引擎边界（诚实说明）

- **代码**：单文件符号 + 跨文件引用图 + 注解类型；**没有**类型推断/跳转语义（不是编译器前端）。
- **Excel**：值、公式、样式指纹、条件格式、合并、定义名称、图表存在性；**没有**图表内容级对比。
- **Word**：段落/修订级；批注与脚注部分覆盖。
- **PDF**：文本层对象级；扫描件没有文本层，会明确列出页号并提示无法比对（OCR 未实现，不在当前路线图上）。
