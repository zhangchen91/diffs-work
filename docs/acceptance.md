## 已知边界（写在代码与文档里，不是遗漏）

- **类型/跳转**：只认源码证据（注解、字面量、`new X()`、interface 自身），没有证据返回「未知」；
  不做类型检查、泛型实例化、重载解析、控制流收窄、跨包解析。
- **PDF**：基于文本层与字符坐标；扫描件（无文本层）会明确提示，不做 OCR 假比对。
- **Excel**：比值、公式、样式指纹、条件格式、合并、定义名称、图表存在性；不做图表内容级对比。
- **CI**：workflow 已写好（unit + browser 两个 job），仓库已推送并在跑；此前长期红着（一个 `patch` 用例在 GNU patch 2.7 下不成立），现已修复。
- **浏览器扩展**：开发态加载可用，未上架商店。
