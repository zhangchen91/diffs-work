# Weekly hours report

How hours get recorded, when a correction needs a lead, and what counts as a normal week.

## How hours are counted

- Billable hours are recorded against a task code.
- Anything without a task code counts as internal time.
- Round each entry up to the nearest quarter hour.
- A correction after the week closes needs a lead's approval.

## Rules of thumb

A normal week is under 40 hours. Two consecutive weeks above 48 hours should be flagged
to the team lead during the Monday sync.

## Where the numbers live

The tracker exports one CSV per week. Files are named `hours-YYYY-WW.csv`.

## Known gaps

Time spent reading documentation is not tracked yet. See the note in the tracker
backlog before adding it.

Time spent in review meetings is tracked only when it has a task code.
