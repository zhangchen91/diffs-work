PPT 的复核有两个常见问题：**页序变了**，和**一页里改了半句话**。
按页码逐页比会把「挪了一页」变成「后面每一页全变了」，所以先对齐页，再比文字。

## 用什么比

读 `ppt/slides/slideN.xml` 里的文本框与其中的文字（`a:t`），以及 `ppt/presentation.xml` 中的**页序**：

- 每页的**标题**与正文要点（不在正文里的备注、页码不计）；
- 页与页之间的顺序；
- 演讲者备注（可选开关，默认不参与）。

不读：版式、母版、动画、转场、图片。

## 怎么判

<Doc kind="step" n="1" title="按页对齐" />

以每页的**标题**为主键、页内文本整体为辅助，找出「同一页」在两边的位置。
找不到对应页 → 这一页是新增或删除。

<Doc kind="step" n="2" title="页内比对" />

同一页里的文字按**段落**比对：新增要点、删除要点、改写要点。
改写同样是「公共前后缀够长才算改」，并在段落内标出改动的字。

<Doc kind="step" n="3" title="整页搬家" />

一页在原处消失、在别处原样出现，内容完全一致 → **移动**，并写明「第 N 页 → 第 M 页」。
这在「先讲结论还是先讲数据」的调整里很常见，也是人最容易漏看的一种改动。

## 结果长什么样

```jsonc
{
  "kind": "pptx",
  "slides": [
    { "index": 7, "title": "财务预测", "status": "changed",
      "changes": [ { "op": "mod", "old": "2026 年收入 1.2 亿", "new": "2026 年收入 1.5 亿" } ] },
    { "index": 3, "title": "团队介绍", "status": "moved", "from": 9 }
  ]
}
```

## 看不到什么

| 看不到 | 为什么 |
|---|---|
| 图片与图表的像素差异 | 属于图片比对 |
| 版式与位置的细微移动 | 版面调整不构成内容变化 |
| 动画 / 转场 | 与内容无关 |
| 备注页 | 默认不参与，可打开 |

<Callout tone="note" title="关于「页数一样但顺序不同」。">
这是最常见也最容易被忽略的一类改动。视图会按对齐结果排列，而不是按页码，
因此一眼能看出「第 9 页变成了第 3 页」，而不是「第 3 到第 9 页全部变了」。
</Callout>

## 常见问题

**每页都是「删 + 加」？** 多半是标题不在同一个文本框里，或两份导出工具把标题拆成了不同的 run。
可以先看视图里对齐后的标题是否一致。

**只有一页变了，但整份都标红？** 检查是否有一页被删除导致对齐全错位；视图会在变更清单里明确列出「第 N 页被删除」。
