## Two directions

```
        person ───── plans / notes / questions ─────▶ agent   (normalised input)
        person ◀──── results / changes / diffs ────── agent   (normalised output: diffs.work)
```

1. Every time an agent changes something, it calls `diff_compare` for a structured diff.
2. The diff lands in the inbox so the person can see which hunks actually need attention.
3. The person's feedback (accept, reject, annotate) goes back to the agent.
