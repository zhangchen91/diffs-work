## 两个方向

```
        人 ───── 计划 / 批注 / 问题 ─────▶ agent     （输入规范化）
        人 ◀──── 结果 / 改动 / 差异 ───── agent     （输出规范化：diffs.work）
```

1. agent 每产出一次改动，就用 `diff_compare` 生成结构化差异；
2. 差异进入 Inbox，人按「哪些 hunk 真的要盯」快速判断；
3. 人的反馈（接受 / 拒绝 / 标注）再回到 agent。
